# v3.7.3 — Purchase cutoff, media dialogs and shared Toolbox dashboard

- Purchase deadlines no longer draft products or return 404. Published pages remain public, with the existing per-product deadline enforcing purchase denial for both products and variations. Keep deadline metadata after processing; store a separate completion marker to avoid reprocessing. Cancellation/rescheduling clears that marker. Earlier drafts are never automatically republished.
- Use the native translated WordPress publication date format with an Edit link and collapsed fields. Set the closed button label per product, defaulting to 此商品已無法購買. WooCommerce single-product and loop buttons show a disabled/non-actionable label after expiry; original buttons remain unchanged before expiry. Existing purchasability filters remain the server-side guard; no stock or price changes.
- Media folders now print CSS once from admin_head or, if media was enqueued late, immediately before the footer initializer. Modal grids reserve folder space independently of upload.php's static layout, including builder mode-grid frames, compact drawers and attachment-details insets. Keep all filtering, moving and folder operations.
- Shared administrators use one Toolbox menu/dashboard showing only shared, enabled, available modules. No per-module top-level links, activation controls, sharing controls or license panel appear in the restricted dashboard. Original registered settings callbacks and capabilities stay in place. Owners retain full access; explicitly turning off the global hide setting retains its existing full-dashboard behavior.
- Add restricted-dashboard rendering assertions, late-style/deduplication checks, 18 native media layout cases, and update WordPress/MySQL deadline tests to require published status and persistent purchase blocking.

No production products were republished or changed. External full-page/CDN caches still require configured purging; these tests do not claim compatibility with every third-party replacement WooCommerce template.
