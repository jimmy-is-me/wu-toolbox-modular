# 電商後台介面（v3.5.2）

## 商品規格表

規格資料仍在 **商品編輯頁** 管理，不新增訂單專用規格欄位。

1. 在「商品規格表設定 → 規格欄位」新增或修改欄位名稱。
2. 在「規格資料」按列填寫尺寸、數字或文字；欄位標籤即時同步。桌面自動換行，手機單欄排列，不需要左右捲動整張後台表格。
3. 可保留格式化備註與媒體庫圖片；按「更新商品」儲存。既有欄位鍵值與資料格式不變，不需要資料搬移。

移除欄位或資料列會先確認；至少保留一個欄位。空白列不會出現在前台。前台規格表的顯示、圖片延遲載入及原有資料不變。

## 隱藏 WC 工具

卡片移至「電商優化工具」。新增四個 **預設關閉** 的獨立開關：

- 商品編輯的進階分頁。
- 商品類型中的組合商品選項。
- 商品編輯的運送方式分頁。
- 商品編輯的連結商品分頁。

儲存後重新開啟商品編輯頁生效。這是顯示設定，不是權限管制：不移除欄位或選項、不停用物流／關聯商品、不改變庫存、不清除商品資料，隱藏欄位的既有值仍隨商品正常儲存。其餘庫存、屬性與變化類型仍可操作；目前分頁被隱藏時會選擇可見分頁。

已是組合商品的商品保留目前選取的「組合商品」，避免更新時誤轉成其他類型。取消隱藏設定並儲存即可恢復完整介面。WooCommerce 設定的「進階」與商品編輯的「進階」是不同開關。

## 效能與驗證

新規格表樣式與腳本只載入商品編輯頁；隱藏工具腳本只在商品編輯頁且相關開關開啟時載入。沒有前台新 JavaScript、前台輪詢、背景排程或外部服務請求。

自動測試涵蓋資料格式、權限、欄位新增／刪除、重新編號、RWD、隱藏欄位仍提交與目前商品類型保留。正式使用前仍應在測試站儲存一筆含庫存、關聯商品及規格表的商品，確認主題、第三方商品資料分頁及其他外掛相容。
