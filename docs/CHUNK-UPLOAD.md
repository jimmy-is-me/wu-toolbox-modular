# 分段上傳

在 **Wu Toolbox → 媒體工具** 啟用「分段上傳」，再從 Toolbox 子選單開啟同名頁面。選取 MP4 並按「開始上傳」。頁面會顯示每段進度；合併並驗證成功後，可直接開啟影片或進媒體庫編輯。

- 預設檔案上限為 50 MB，並遵循 WordPress 多站點的上傳類型、檔案大小及儲存空間設定。
- 預設每段最多 1 MB，會依 PHP 單次上傳及表單限制縮小。上傳中可暫停或取消。遇到短暫斷線會有限次重試；重新整理後，在 HTTPS 網站可重新選擇同一支影片續傳。瀏覽器阻擋本機儲存時，仍能在同一頁暫停及續傳。
- 媒體登錄使用 WordPress 的上傳路徑及附件資料。暫存由上傳人獨立持有，閒置一小時或建立滿一天後到期，由 WP-Cron 清理。取消只清除未完成的分段。

## 主機設定

暫存使用 PHP 的系統暫存目錄。若主機限制該路徑，可在 wp-config.php 定義 WUTM_CHUNK_UPLOAD_TEMP_DIR，指定 PHP 可寫入的私人目錄。目錄必須位於網站公開目錄及媒體庫以外。多台 PHP 主機需共用具備檔案鎖的私人儲存，或設定管理介面請求固定送往同一台主機。

反向代理或 CDN 若另有單次請求限制，可透過 wutm_chunk_upload_part_bytes 過濾器設定較小的分段位元組數。變更分段大小會套用到新工作。複合的 HTTP 請求會包含表單資料，請保留額外空間。一般 WordPress 網站的媒體上傳設定沿用原值。

更新後從模組卡片啟用即可測試。若要停用，先取消未完成的工作再停用模組，已登錄影片仍能在媒體庫使用。
