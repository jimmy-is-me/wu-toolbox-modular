# v3.8.4

新增「訂單報表匯出」模組，分類為「電商工具」，設定入口為 Toolbox → 訂單報表匯出。

完整保留使用者提供的「WooCommerce 中文訂單報表匯出 V3」：

- 全部期間／今天／本月／上月、自選日期與訂單狀態篩選，使用網站時區。
- 22 個內建欄位、11 個常用預設欄位，以及訂單／商品項目／運送項目的自訂 Meta 欄位偵測、手動加入、中文建議、排序、改名及勾選。
- 最近 100 筆符合訂單的欄位偵測、前 30 列實際匯出內容預覽；預覽不儲存設定、不下載資料。
- 每張訂單一列或每個商品項目一列；訂單金額只在第一列輸出，避免重複加總。保留累計退款、退款後淨額、無商品訂單及 JSON 欄位。
- 分批讀取、UTF-8 BOM CSV、中文字與儲存格換行、公式注入防護，以及電話／SKU／長數字文字保護選項。
- 每位使用者獨立儲存／還原設定、訂單數查詢、Nonce 與管理權限驗證。

僅更動類別識別、設定選單與頁面外觀；原始設定鍵、操作名稱、欄位及匯出邏輯保留。逐字保留測試會逆轉明列的整合改動，核對提供程式的摘要；不以更新摘要掩蓋功能修改。

模組預設關閉，只在後台載入；不定時自動匯出、不寄信、不發送外部請求、不建立公開匯出檔案。偵測到原匯出 Snippet 時暫停重複載入，請先停用舊程式，原個人設定仍可沿用。

CSV 含訂單個資，請妥善保存。CSV 並非 XLSX，Excel 對單引號文字保護的顯示仍依開啟方式而異。預覽與匯出各自讀取當下資料，期間訂單異動可能造成差異。
