# v3.6.9

Admin appearance is integrated into the existing admin-bar-cleaner settings page, not a separate module or top-level menu. The supplied five styles and all 17 option values are retained under `np_admin_opts`, including fonts, menu accent, login/bar scopes, date/site heading and footer fields. Native remains the default. Unconfigured installations do not gain a new footer or remove the WordPress logo. Existing cleaner footer settings take precedence. Existing standalone style class avoids duplicate boot registration.

The new clean-youtube-player media module preserves the supplied player functionality and `cyp_options`: ten switches, brand color, lazy facade/Plyr, eager deferred loading, official iframe parameters, no-JS fallback, exclusive playback and facade restoration on ended. Settings are under Toolbox and use the normal Settings API authorization. Existing standalone player filtering takes precedence to avoid duplicate wrappers. Provider host matching is strict; playlists, start/end time and loop URLs use iframe fallback. CDN failures can retry and player readiness has a bounded timeout. Official deprecated parameters remain visible as compatibility settings, with limitations explained; no ad-blocking or branding-removal guarantee.

oEmbed cache cleanup remains available on each authorized explicit save but runs in background keyset batches of at most 100 rows, invalidating the affected metadata caches. Sanitization no longer performs an unbounded database DELETE. No recurring scan is started simply by visiting settings. Visitors without a visible admin bar do not receive style/font resources. Player dependencies are loaded only when a supported embed is present, with interaction-driven loading by default; YouTube thumbnails remain third-party requests.

The media encoder retains the original data/actions and WebP ring while removing the second hero/headline and unused hero CSS. Responsive tests cover 320–1440 px; style/player tests cover all themes, fields, retry, playback exclusivity and restoration. Policy tests cover native defaults, visitor isolation, old footer precedence, original settings names, iframe fallbacks and bounded cleanup.
