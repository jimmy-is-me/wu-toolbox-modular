# v3.8.3

新增「PAYUNi 物流工具」，位於「電商第三方金物流」分類，緊接 PAYUNi 付款工具；設定入口為 Toolbox → PAYUNi 物流工具。

## 功能與來源

整合使用者提供的 `wu-payuni-shipping-1.1.1.zip`，保留全部 36 個來源檔案。來源與必要修正的逐檔摘要位於開發測試清單 `tests/payuni-shipping-source-files.json`。

- 7-ELEVEN C2C 常溫／冷凍及黑貓常溫／冷凍／冷藏。
- 運送區域、運費、免運門檻／優惠券、黑貓包裹規格及配送日期設定。
- 傳統結帳選店、物流資料儲存、訂單建單動作、貨態通知／查詢、狀態對應、訂單列表／明細及標籤列印／下載。
- 原有商家設定鍵、運送方式 ID、訂單欄位及 API 請求資料保留。付款與物流共用 PAYUNi 商家金鑰，物流測試模式獨立設定；修改共用金鑰也會影響付款工具。
- 設定使用共用後台外觀並遮蔽金鑰，保留舊 WooCommerce 物流設定網址轉向 Toolbox，不重複註冊付款設定頁。

## 安全與相容

新模組預設關閉；啟用不會自動新增運送區域、修改金鑰或發出物流請求。新安裝物流預設測試模式，原 7-ELEVEN 建單開關預設關閉，既有明確設定保留。偵測獨立版物流外掛時不重複載入。

必要修正包含通知簽章／商家與物流訂單對應、重複／過期通知保護、同訂單建單鎖、個別訂單權限與防偽驗證、查詢失敗不覆寫物流資料、避免全域時區變更、修正 PDF 回應標頭、冷凍選店溫層及以實際運送實例取得包裹規格。原始腳本保留，執行時採用不影響其他物流欄位的選店腳本；除錯日誌不輸出原始個資及金鑰。

選店沿用傳統結帳，未新增區塊結帳選店介面；不為整個 Toolbox 額外宣告或改變相容性。保留訂單列表與編輯的傳統／HPOS 程式支援，但仍須依實際商店環境完成商家測試。

自動測試使用隔離 WordPress／WooCommerce 與模擬回應，沒有對正式服務建單、收款或寄貨。商家正式環境仍應先測試選店、五種運送方式、建單、貨態及標籤流程。
